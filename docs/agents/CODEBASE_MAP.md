## Purpose

`shop-py-moneyed` is SHOP's fork of the upstream `py-moneyed` library. It supplies every SHOP
service with a single `Money` type (a `Decimal` amount bound to an ISO 4217 currency), the full
currency registry with correct minor units, arithmetic that refuses to mix currencies silently, and
Babel-backed display formatting. It does **not** handle exchange rates, tax, basket totals, or
discounts — those live in consuming services. [cite: source:product-note@r1]

## Key concepts

| Domain term | Type / symbol | File |
|---|---|---|
| **Money** | `Money` class | `src/moneyed/classes.py` |
| **Currency** | `Currency` class, module-level constants (`EUR`, `USD`, `JPY`, …) | `src/moneyed/classes.py` |
| **Minor unit** | `Currency.sub_unit` (int; JPY = 1, EUR = 100, KWD = 1000) | `src/moneyed/classes.py` |
| **Settlement amount** | `Money.round(ndigits)` — rounds to minor unit; uses active decimal context (default `ROUND_HALF_EVEN`) | `src/moneyed/classes.py` |
| **Display amount** | `format_money(money, locale=…)` — Babel-formatted string; never parse back | `src/moneyed/l10n.py` |
| **Currency registry** | `CURRENCIES: dict[str, Currency]`, `CURRENCIES_BY_ISO: dict[str, Currency]` | `src/moneyed/classes.py` |
| **Allocation** | `Money.allocate(ratios: list[int]) -> list[Money]` — exact split, leftovers to first parts | `src/moneyed/classes.py` |
| **Currency mismatch** | `TypeError` raised on cross-currency arithmetic or comparison (planned: `CurrencyMismatchError(TypeError)`) | `src/moneyed/classes.py` |
| **Subunit amount** | `Money.get_amount_in_sub_unit() -> int` — truncates; callers must `round()` first (known gap) | `src/moneyed/classes.py` |

`Money` is immutable: `amount` and `currency` are `Final`; all arithmetic returns a new instance.
`amount` is always `Decimal`; float inputs are accepted with a `DeprecationWarning`. [cite: src/moneyed/classes.py]

## Where to change what

| Kind of change | Files to change | Tests to add/update |
|---|---|---|
| Add or fix a currency (e.g. XCG, ZWG) | `src/moneyed/classes.py` — add `add_currency(...)` call in the active-currencies block | `tests/test_moneyed_classes.py` — `test_all_babel_currencies` will pass once added; add a specific test |
| Fix or extend arithmetic (`+`, `-`, `*`, `/`, `%`) | `src/moneyed/classes.py` — `Money` operator methods | `tests/test_moneyed_classes.py` — `TestMoney` class |
| Add `CurrencyMismatchError` | `src/moneyed/classes.py` — new exception, update `__add__` and `__truediv__` | `tests/test_moneyed_classes.py` — update mismatch tests to assert the new type and message |
| Enforce half-even in `Money.round()` | `src/moneyed/classes.py` — pass `rounding=ROUND_HALF_EVEN` to `quantize()` | `tests/test_moneyed_classes.py` — `test_round`, `test_round_context_override` |
| Add `Money.discounted(percent)` | `src/moneyed/classes.py` — new method returning unrounded `Money` | `tests/test_moneyed_classes.py` — new test class |

| Change display formatting | `src/moneyed/l10n.py` | `tests/test_l10n.py` |
| Bump the release version | `setup.cfg` (version field) **and** `docs/conf.py` (release field) — same commit | — |

## Build and test

```
# Install (once per worktree)
$python -m pip install -e ".[tests]"

# Lint
$python -m black --check --quiet src tests
$python -m isort --check-only src tests
$python -m flake8 src tests

# Type-check (uses a separate venv the platform provisions)
$python -c "import subprocess, sys, pathlib; p = pathlib.Path('.venv/mypy-env') / ('Scripts' if sys.platform == 'win32' else 'bin') / 'python'; raise SystemExit(subprocess.run([str(p), '-m', 'mypy']).returncode)"

# Full test suite (includes doctests)
$python -m pytest --mypy-ini-file=setup.cfg
```

- pytest configuration is in `setup.cfg` (`[tool:pytest]`): `--doctest-modules`, `--doctest-glob='*.rst'`,
  `-Werror`, testpaths = `tests/`. [cite: setup.cfg]
- Four tests are **known, accepted failures** that stay in the gate. Never deselect any of them:
  - `tests/test_money.yaml::can_instantiate_money` [cite: tests/test_money.yaml]
  - `tests/test_money.yaml::instantiating_money_without_currency_gives_error` [cite: tests/test_money.yaml]
  - `tests/test_moneyed_classes.py::TestMoney::test_str` [cite: tests/test_moneyed_classes.py]
  - `tests/test_moneyed_classes.py::test_all_babel_currencies` (Babel added XCG/ZWG which `CURRENCIES` lacks) [cite: source:transcript-run-66c5f847@r1]
- mypy is strict (`disallow_untyped_defs`, `warn_return_any`, etc.); `tests/test_l10n.py` has
  `disallow_untyped_defs = False`. [cite: setup.cfg]
- Releases: tag `v<version>` on the release commit after QA + product-owner sign-off; no PyPI.
  SHOP services install from the tag. [cite: source:how-we-release@r1]

## Risky areas

| Area | Risk | Notes |
|---|---|---|
| `Money.round()` | Does not explicitly pass `ROUND_HALF_EVEN`; relies on the active decimal context | Known gap; callers rely on Python's default. A fix is planned. [cite: src/moneyed/classes.py] |
| `get_amount_in_sub_unit()` | Truncates toward zero instead of rounding | Callers that pass an unrounded `Money` get a wrong payment-provider amount. Known gap. [cite: src/moneyed/classes.py] |
| `CURRENCIES` dict | Mutable at runtime via `add_currency()` | SHOP services must never call `add_currency()`; new currencies enter only through a reviewed change. [cite: source:transcript-run-a080ea35@r1] |
| Known-failing tests (4) | `test_money.yaml::can_instantiate_money`, `test_money.yaml::instantiating_money_without_currency_gives_error`, `TestMoney::test_str`, `test_all_babel_currencies` | Accepted known failures; do not remove or deselect any of them. [cite: tests/test_money.yaml], [cite: tests/test_moneyed_classes.py] |
| Arithmetic changes | Any change to rounding or arithmetic result is a minor-version bump | Must be flagged at the top of `CHANGES.rst`. [cite: source:how-we-release@r1] |
| Float inputs | Accepted via `DeprecationWarning`, not yet a `TypeError` | Do not silently widen float support in new code. [cite: src/moneyed/classes.py] |

  paths: `src/moneyed/classes.py` [cite: source:product-note@r1]
- `Currency` (business term): an ISO 4217 code with its minor unit;
  paths: `src/moneyed/classes.py` [cite: source:product-note@r1]
