## Key types and public API

### `Currency` [cite: src/moneyed/classes.py]
Represents an ISO-4217 currency.  Notable attributes: `code` (str), `numeric`
(str | None), `sub_unit` (int – minor units per major unit, e.g. 100 for EUR,
1 for JPY).  All active and historical currencies are registered as
module-level constants (e.g. `EUR`, `USD`, `JPY`).

### `Money` [cite: src/moneyed/classes.py]
Combines a `Decimal` amount with a `Currency`.  Immutable value object.
Supports `+`, `-`, `*`, `/`, `abs`, `round`, `%`, comparisons.

#### `Money.allocate(ratios: list[int]) -> list[Money]` [cite: src/moneyed/classes.py]
Splits a `Money` amount among N parties by integer ratios without losing or
creating minor units.  Algorithm: convert the total to minor units, floor each
share, distribute any remainder one minor unit at a time to the first parts in
order.  Negative amounts are handled symmetrically (the extra unit goes to the
first part as the largest-magnitude share).  Raises `ValueError` if `ratios`
is empty, contains a negative value, or sums to zero.

### `format_money` [cite: src/moneyed/l10n.py]
Formats a `Money` for display using Babel's `format_currency`.

## Money and rounding convention

`Money.allocate` is the canonical way to split an amount without losing a
minor unit.  All other arithmetic (`+`, `-`, `*`, `/`) returns an unrounded
`Money`; callers that need a specific precision call `.round()` themselves.
